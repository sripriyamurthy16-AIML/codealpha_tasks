## 📌 Task 1 – LingoFlow: Language Translation Tool

LingoFlow is a simple and user-friendly language translation web application built using Python and Streamlit.

### ✨ Features

* 🌍 Translate text between multiple languages
* 🇬🇧 English
* 🇮🇳 Hindi
* 🪷 Telugu
* 🌿 Kannada
* 🌺 Tamil
* ⚡ Fast translation using Google Translator
* 🎨 Clean and responsive Streamlit interface
* ✨ Simple and easy-to-use design

### 🛠️ Technologies Used

* Python
* Streamlit
* Deep Translator
* Google Translator

### 🚀 How to Run

Navigate to the Task 1 folder:

```bash
cd "TASK 1_language_translation"
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run main.py
```

## 📌 Task 2 – FAQFlow: FAQ Chatbot

FAQFlow is an NLP-based FAQ chatbot that identifies the most relevant answer to a user's question using **TF-IDF and Cosine Similarity**.

### ✨ Features

* 🤖 FAQ chatbot interface
* 💬 Accepts natural-language questions
* 🔤 Text preprocessing using NLTK
* 📊 TF-IDF based text representation
* 🔍 Cosine Similarity for finding relevant answers
* ☁️ Cloud-computing related FAQs
* 🎨 Clean and responsive Streamlit interface

### 🛠️ Technologies Used

* Python
* Streamlit
* NLTK
* Scikit-learn
* TF-IDF
* Cosine Similarity

### 🚀 How to Run

Navigate to the Task 2 folder:

```bash
cd "TASK 2_faq chatbot"
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run main.py
```
